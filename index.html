    18:20 · DAY 1第一章

    交接

    晚饭时间到了。你把服务器地址、账号和一句“帮我看着点”交给了它，然后退出了游戏。

    你不需要守在黑框终端前猜它有没有连上。你在控制台里下达的是指令，本机节点回报的是实况： 正在排队就是正在排队，掉线就是掉线，绝不会把卡住画成“运行中”。

    • 一次性配对控制台生成短时配对码，本机一条命令完成加密接入，账号凭据不裸奔。
    • 可靠送达控制指令与配置变更全程受认证与回执保护，弱网下不丢指令、也不重复执行。
    • 进度看得见从接过任务到站在出生点值守，每一步都能在时间线里回看。

    21:40 · DAY 1第二章

    断线

    21:40，服主重启了服务器。连接在一瞬间断开，聊天框里刷过一行红字。

    它不会原地卡死，也不会无脑刷屏式地反复撞门。网络抖动、服主重启这类可恢复的掉线会自动按节奏重连； 账号失效、版本不符这类需要你出手的问题，则会带着明确原因停下，等你醒来处理。

    • 自动恢复可恢复故障按节奏退避重连；本机节点断网恢复后，值守任务也会自动续上。
    • 互不牵连每只 Bot 各自独立运行，单个任务出现异常不会拖垮其他助手。
    • 现场可回溯事件时间线、运行日志与异常提醒集中呈现，第二天一早就能看清昨晚发生了什么。

    03:00 · DAY 2第四章

    守则

    凌晨三点，服务器里只剩它和几只蝙蝠。没有人看着的时候，正是守则起作用的时候。

    1. I
      只去被授权的服务器。没有对目标服务器的自动化授权，就不出发。
    2. II
      不规避反作弊，不刷屏，不做未授权挂机。这些是明确拒绝的产品红线。
    3. III
      状态如实呈现。排队、断线或失败都直说，不制造“看起来在线”的假象。
    4. IV
      凭据加密隔离。配对信息与账号密钥按最小作用域授权，不向无关插件暴露。
    5. V
      插件先声明，后运行。所有扩展能力经过受控接口，不赋予任意系统权限。
    6. VI
      拿不准的扩展，宁可不跑。未经安全校验的私有插件默认拒绝加载，把风险挡在门外。
    7. VII
      你的数据归你自己。面向个人与小团队的自托管助手，不做公共 Bot 托管农场。

    这是我们从第一天起立下的产品原则与合规承诺，具体细则可在下方手册中查阅。

      12:00 · 常见解答

      守夜人常被问到的事

      关于账号、掉线、插件权限与合规边界的常见疑问都在这里。

      我必须使用正版账号吗？
      不一定。创建 Bot 时可根据目标服务器选择离线模式、Microsoft 正版账号或第三方认证账号。敏感凭据均会加密保存，并仅在对应作用域内使用。
      电脑关机了，Bot 还会在线吗？
      Bot 运行在你绑定的节点设备上。电脑关机后，该节点上的 Bot 会如实显示离线，待设备重新上线后自动续接。若想离开电脑继续值守，可以把节点放在常开的私有服务器，或使用 Android 便携节点。
      服务器重启或网络波动，需要我手动重连吗？
      不需要。遇到断线或短暂超时等可恢复情况，Bot 会按节奏自动退避重连；如果是账号失效、被服务器踢出或版本不兼容等需要人工介入的问题，控制台会给出清晰原因与排查建议。
      支持哪些 Minecraft 版本？多人可以一起管吗？
      面向 Minecraft Java 版服务器，创建时推荐开启版本自动检测。控制台支持团队工作区，可按管理员、操作员与只读成员分配权限，协作照看多只 Bot。
      一部安卓手机能同时跑几只 Bot？
      为了保证续航、内存与后台稳定性，Android 便携节点专注托管单只 Bot；需要同时值守多只 Bot 时，建议使用电脑或常开服务器节点。
      插件可以做什么，不能做什么？
      插件可以通过官方 SDK 响应游戏事件、查询周围环境与背包、发起受控动作以及上报结构化监控数据。插件无法读取本机文件、不能任意访问网络或系统进程，也无法触碰账号原始凭据与底层连接对象。
      为什么自己写的私有插件默认不能直接跑？
      为了防止不受信任代码危及你的设备与服务器，私有或未经过安全校验的扩展默认处于“拒绝加载”状态，直到满足对应的安全隔离与验证要求。
      声明了权限，插件就能在任何时候执行动作吗？
      不是。权限声明只是插件的能力需求清单，实际执行前还必须经过你的安装授权与运行时的安全及状态检查。
      可以拿它在任意公共服务器上挂机吗？
      不可以。你必须明确拥有对目标服务器进行自动化的授权，并遵守 Minecraft Usage Guidelines。反作弊规避、刷屏与未授权挂机是明确不支持的产品红线。
      这是 Mojang 或 Microsoft 的官方产品吗？数据存在哪？
      不是。MC Bot Studio 是独立项目，与 Mojang / Microsoft 无关联也无官方背书，也不是公共 Bot 托管农场。平台支持完全自托管，配置与运行记录保存在你自己掌控的环境中。

      没有匹配的问题。
